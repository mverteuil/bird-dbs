# Pre-commit Hooks Configuration

This repository uses [pre-commit](https://pre-commit.com/) to ensure code quality and consistency across all three builders.

## Installation

### 1. Install pre-commit

```bash
# Using uv (recommended)
uv tool install pre-commit

# Or using pip
pip install pre-commit

# Or using homebrew (macOS)
brew install pre-commit
```

### 2. Install the git hooks

```bash
# From repository root
pre-commit install

# Optional: Install for all hook types
pre-commit install --hook-type pre-commit
pre-commit install --hook-type pre-push
```

## Hooks Overview

### General Hooks

- **check-yaml** - Validates YAML syntax
- **end-of-file-fixer** - Ensures files end with newline
- **trailing-whitespace** - Removes trailing whitespace

### Python Hooks (IOC + Wikidata builders)

- **ruff-check** - Fast Python linter (import order, code quality)
- **ruff-format** - Fast Python formatter (replaces black)
- **pyright** - Type checking
- **semgrep** - Security and bug pattern detection

### Rust Hooks (eBird builder)

- **cargo fmt** - Rust code formatting
- **cargo clippy** - Rust linting (treats warnings as errors)

### Other Hooks

- **prettier** - JavaScript/CSS/HTML formatting
- **shellcheck** - Shell script linting
- **hadolint** - Dockerfile linting
- **yamllint** - YAML linting
- **actionlint** - GitHub Actions workflow linting
- **toml-sort** - TOML file sorting

## Usage

### Automatic (on git commit)

Hooks run automatically when you commit:

```bash
git add .
git commit -m "Your commit message"
# Hooks run automatically and may modify files
```

If hooks modify files:
```bash
git add .  # Re-add modified files
git commit -m "Your commit message"
```

### Manual (run on all files)

```bash
# Run all hooks on all files
pre-commit run --all-files

# Run specific hook
pre-commit run ruff-check --all-files
pre-commit run cargo-fmt --all-files

# Run hooks on specific files
pre-commit run --files ioc-builder/*.py
```

### Skip hooks (emergency only)

```bash
# Skip all hooks for one commit
git commit -m "Emergency fix" --no-verify

# Skip specific hook
SKIP=semgrep git commit -m "Your message"
```

## Hook Stages

Some hooks run at different stages:

- **pre-commit**: Runs before every commit (most hooks)
- **pre-push**: Runs before pushing to remote
- **manual**: Only runs when explicitly invoked

To run pre-push hooks:
```bash
pre-commit run --hook-stage pre-push --all-files
```

## Troubleshooting

### Hook fails with "command not found"

**Problem:** Pre-commit can't find a required tool (e.g., cargo, shellcheck)

**Solution:**
```bash
# Ensure required tools are installed
# For Rust hooks
rustup install stable

# For shellcheck (macOS)
brew install shellcheck

# For hadolint (Docker linting)
brew install hadolint
```

### Python import errors in pyright

**Problem:** `pyright` hook fails with import errors

**Solution:**
```bash
# Install project dependencies first
cd ioc-builder
uv sync --extra dev

cd ../wikidata-builder
uv sync --extra dev
```

### Rust hooks fail in CI

**Problem:** `cargo fmt` or `cargo clippy` fail in CI but pass locally

**Solution:**
```bash
# Update Rust toolchain
rustup update stable

# Run with same settings as CI
cd ebird-builder
cargo fmt --check
cargo clippy -- -D warnings
```

### Ruff fixes break code

**Problem:** Ruff auto-fixes introduce issues

**Solution:**
```bash
# Review changes before committing
git diff

# Revert unwanted changes
git checkout -- file.py

# Or skip ruff for one commit
SKIP=ruff-check git commit -m "Message"
```

### Semgrep false positives

**Problem:** Semgrep reports false security issues

**Solution:**
```bash
# Review semgrep findings
semgrep --config=auto ioc-builder/ wikidata-builder/

# Add nosemgrep comment to suppress specific finding
# nosemgrep: rule-id
dangerous_code()

# Or exclude file in .pre-commit-config.yaml
```

## Updating Hooks

```bash
# Update all hooks to latest versions
pre-commit autoupdate

# Update specific hook
pre-commit autoupdate --repo https://github.com/astral-sh/ruff-pre-commit
```

## CI Integration

Pre-commit runs in CI via GitHub Actions. See `.github/workflows/pre-commit.yml` (if configured).

To run the same checks locally:
```bash
pre-commit run --all-files --show-diff-on-failure
```

## Configuration

Hook configuration is in `.pre-commit-config.yaml`. To modify:

1. Edit `.pre-commit-config.yaml`
2. Update hook versions with `pre-commit autoupdate`
3. Test with `pre-commit run --all-files`
4. Commit changes

## Disabling Hooks

### Temporarily (one commit)

```bash
git commit --no-verify
```

### Permanently (not recommended)

```bash
pre-commit uninstall
```

### Per-file (add to .pre-commit-config.yaml)

```yaml
- id: ruff-check
  exclude: ^path/to/legacy/code\.py$
```

## Best Practices

1. **Run hooks before committing**: `pre-commit run --all-files`
2. **Keep hooks updated**: `pre-commit autoupdate` monthly
3. **Don't skip hooks**: Fix issues rather than bypassing checks
4. **Install early**: Set up pre-commit when starting work on the repo
5. **Review auto-fixes**: Check what ruff/cargo-fmt changed before committing

## Hook Details

### Python: ruff-check vs ruff-format

- **ruff-check**: Linting (import order, unused imports, complexity, etc.)
- **ruff-format**: Formatting (line length, indentation, etc.)

Both are configured in `pyproject.toml` for each builder.

### Rust: cargo fmt vs cargo clippy

- **cargo fmt**: Formatting (style consistency)
- **cargo clippy**: Linting (best practices, performance, correctness)

Configured in `ebird-builder/Cargo.toml` and `rustfmt.toml`.

### Pyright vs semgrep

- **pyright**: Type checking (catches type errors)
- **semgrep**: Security and bug patterns (catches vulnerabilities)

Use both for comprehensive Python code quality.
